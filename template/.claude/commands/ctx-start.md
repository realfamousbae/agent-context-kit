description: Start of session — read the start card, record the goal, claim the area

Follow "Entry" in `.context/PROTOCOL.md`:

1. Unless a ctx card was injected at session start, run `sh .context/bin/ctx brief`.
2. Tell the user in 2–4 lines what is new from others and which questions are addressed to you.
3. For the user's task: `sh .context/bin/ctx start --goal "<what, and how we know it is done>" --area "<paths>" --model <your model id>`. If the area overlaps someone's claim, ask with `ctx ask` and tell the user.
4. Then work by your own plan; do not re-read `.context/` unless something is unclear.
